# hub-saude

Hub de Saúde Pessoal: hackathon Gama House × desafio Rivio (demo em 14/11/2026).

Junta exames em PDF ou foto, extrai os resultados com IA, mostra a evolução de cada exame com a faixa de referência e compartilha um resumo com o médico mediante consentimento. Todo número aponta para o documento original.

- Contexto, estratégia e cronograma: [`docs/contexto.md`](docs/contexto.md)
- Regras para quem programa (e para o Claude Code): [`CLAUDE.md`](CLAUDE.md)
- Dados de teste (laudos sintéticos + gabarito): [`tools/gerador-laudos/`](tools/gerador-laudos/README.md)

Somente dados sintéticos ou do próprio time.
